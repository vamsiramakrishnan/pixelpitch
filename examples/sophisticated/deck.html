Pixelpitch — 05 Feature Grid

Six pillars of the rendering pipeline.

05 / 12
▦

Render before decide

Real Chromium computes the layout. Static analysis cannot resolve flex / grid / flow geometry.

PLAYWRIGHT
◈

Visual units, not DOM

Classification atom is a connected visual region — a card, a bullet, a chart — not a single tag.

CLUSTERER
⊞

Three-tier classifier

Rules → heuristics → LLM. Closed-vocabulary patterns short-circuit ~90% of decisions.

TIER 0–3
◐

Confidence aware

Every decision carries a confidence score. Low-confidence triggers a dual-emit safety net.

CONFIDENCE
✓

Self validating

SSIM + OCR oracle catches regressions. Failing regions auto-promote to raster and re-emit.

ORACLE
⌘

Cache aggressively

Structural-signature cache hits 60–80% within a generator after warmup. Reuse is free.

slidify
NEW WAY
✓

✓
Cards, dividers, badges are native rounded rectangles.
✓
Designers edit fonts, colors, alignment in PowerPoint directly.
✓
Only complex visuals (Chart.js, blur effects) rasterize.
✓
Output is 4 MB instead of 50 MB. Email-friendly out of the box.
