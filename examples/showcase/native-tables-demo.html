slide 3 · native vs raster

Where the matrix draws the line

native — editable

Translatable to PPTX shapes

Every primitive PowerPoint understands directly. Edit text, change colors, update tables — no pixel surgery required.

  • Text runs (color, font-*, italic, underline)
  • Linear / radial / conic gradients
  • border-radius + box-shadow
  • <table> with header rows and spans
  • clip-path: inset() / circle() / common polygons
  • SVG ≤200 primitives + KaTeX / Shiki text
raster — preserved visually

Pixel-cropped fallback

PPTX has no equivalent — slidify embeds a screenshot of the affected region so the visual is preserved at the cost of editability.

  • CSS filter (blur / brightness / hue-rotate)
  • backdrop-filter (frosted glass)
  • mix-blend-mode
  • background-image: url() (no fetch+embed yet)
  • <canvas> / WebGL / Three.js (single frame)
  • 3D transforms (matrix3d, preserve-3d)
