Pixelpitch — Features

Six pillars of the rendering pipeline.

03 / 08
▦

Render before decide

Real Chromium computes layout. Static analysis cannot resolve flex/grid/flow geometry.

◈

Visual units, not DOM

The classification atom is a connected visual region — a card, a bullet, a chart — not a single tag.

⊞

Three-tier classifier

Rules → heuristics → LLM. 70% decided free, 20% by score, 10% adjudicated.

◐

Confidence aware

Every decision carries a confidence. Low confidence triggers dual-emit fallback.

✓

Self validating

SSIM + OCR oracle catches regressions. Failing regions auto-promote to raster and re-emit.

⌘

Cache aggressively

Structural hashes hit 60–80% within a generator after warmup. Decisions are cheap to reuse.
