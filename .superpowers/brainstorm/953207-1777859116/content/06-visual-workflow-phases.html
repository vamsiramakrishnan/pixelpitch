The principle: At every phase, the workspace shows a visual artifact that reflects the user's decisions — not a chat log they have to scroll through. The chat pane handles conversation. The workspace handles the state of the deck. Questions that need visual input (tone, evidence type, theme) render as interactive cards in the chat. Answers materialize as visible state in the workspace. The user always knows where they are and what's decided.
