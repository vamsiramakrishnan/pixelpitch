Pixelpitch — 05 Feature Grid

Six pillars of the rendering pipeline.

05 / 12
▦

Render before decide

Real Chromium computes the layout. Static analysis cannot resolve flex / grid / flow geometry.

PLAYWRIGHT
◈

Visual units, not DOM

Classification atom is a connected visual region — a card, a bullet, a chart — not a single tag.

CLUSTERER
⊞

Three-tier classifier

Rules → heuristics → LLM. Closed-vocabulary patterns short-circuit ~90% of decisions.

TIER 0–3
◐

Confidence aware

Every decision carries a confidence score. Low-confidence triggers a dual-emit safety net.

CONFIDENCE
✓

Self validating

SSIM + OCR oracle catches regressions. Failing regions auto-promote to raster and re-emit.

ORACLE
⌘

Cache aggressively

Structural-signature cache hits 60–80% within a generator after warmup. Reuse is free.

Pixelpitch — 13 Decoration showcase
Decoration system

Six layered styles — each row of cards uses a different decoration hint.

Hero
4-corner mesh glow
Stripe / Vercel hero look. Brand palette → 4 translucent radial blobs at the corners.
Spotlight
1 huge centered blob
For dramatic CTA backgrounds — a single glow centered in the surface.
Aurora
3 horizontal bands
Northern-lights effect — three blobs stacked vertically across the surface.
Glass
Frosted depth
Rim highlight + hairline + inset glow. Looks like brushed glass on a dark base.
Tactile
Button-like surface
Strong rim highlight + thin border. Implies a clickable, raised affordance.
Recessed
Inset depression
Inset shadow only — gives the impression of a sunken or pressed surface.
